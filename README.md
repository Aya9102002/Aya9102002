### 🚀 Featured Projects

#### 👶 [Moomy & Me](https://github.com/Aya9102002/moomy-and-me)
A comprehensive healthcare platform for expecting mothers and young children.  
Built with **Node.js, Express.js, Flutter, MySQL**  
Features: User authentication with OTP verification, doctor appointment booking, pregnancy tracking, vaccination reminders, community posts & chat, online consultations, nutritional articles, and a baby products store

#### 🎮 [Crash Bash Keeper](https://github.com/Aya9102002/crash-bash-bot)
An automated goalkeeper robot for a table game that detects and blocks the ball in real time.  
Built with **Python (OpenCV), C++, Arduino, Raspberry Pi**  
Features: Real-time ball tracking with OAK-D camera, trajectory prediction using Kalman filter, motor-controlled striker (solenoid), scoring system with laser & LDR sensors
